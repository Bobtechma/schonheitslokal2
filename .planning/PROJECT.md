# Project: Schönheits Lokal

## Context
Schönheits Lokal is a premium beauty salon based in Switzerland, focused on high-end hair and beauty services. The project is a booking management platform that handles service selection, professional availability, and appointment scheduling with a multi-language (Swiss-German and Portuguese) interface. The design follows a sleek "Pink/Purple" glassmorphism aesthetic tailored for a luxury salon experience.

## Tech Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS, Lucide Icons, Glassmorphism UI.
- **Backend & DB**: Supabase (PostgreSQL, Edge Functions, Auth).
- **Payments**: Stripe Integration.
- **Localization**: Swiss-German (de-CH) and Portuguese (pt-BR).

## Core Modules
1. **Booking System**: Multi-step flow for selecting services, dates, professionals, and time slots.
2. **Professional Management**: Real-time availability tracking per professional, including business hours and blocked dates.
3. **Admin Dashboard**: Daily and weekly views for managing appointments, sales, and professional schedules.
4. **Service Catalog**: Categorized services with upselling features (UpsellServiceStep).
5. **Localization Store**: Centralized language management for a multilingual client base.
